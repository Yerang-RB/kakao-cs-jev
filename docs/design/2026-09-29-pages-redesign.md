## 사용자 결정
- 상단 바 **A안**: 상단 유지. 현재 화면 밑줄(accent 2px) · 「상담 큐」 긴급 배지 · 봇 상태 점(정상 초록 / 이상 빨간 알약) · 오른쪽 사용자 메뉴(이름·이메일·역할 · 비밀번호 변경 · 로그아웃). 폰은 봇 점 + 사용자 동그라미만, 이동은 하단 탭.
- 처리 기록도 **행 → 오른쪽 상세**(상담 큐와 같은 틀, 767px 이하는 목록 ↔ 전체 화면 상세).
- 통계 카테고리 막대 **단색**(accent, 상위 3개 진하게 나머지 연하게) — 기존 「카테고리 고정 색」 규칙 폐기.
- 새 기능 채택: 처리 기록 **「교정」 필터**(일치·불일치·교정 전) · **50건씩 페이지**.
- 운영 설정: 저장 형식(ms·0~1)은 그대로, **화면에서만 초·%**로 입출력. 봇·API 불변.

## 처리 기록
- 필터: 기간 버튼(오늘·7일·30일·전체, 기본 전체) · 이름 붙은 선택(카테고리·봇 처리·결과·교정) · 검색 · 시드 스위치. 선택은 바꾸면 바로 적용.
- 목록: KST 날짜 묶음 머리(「오늘 · 9월 29일 (월)」), 한 줄 행 = 시각 · (긴급 점)고객 · 문의 · 봇 분류+확신도 막대·% · 결과 알약 · 교정(일치/불일치/—). 긴급·후속 점수와 봇 처리 열은 상세로.
- 결과 알약: 대기(테두리) · 처리 중 · 담당(accent-soft) · 상담원 완료/자동응답/무음(회색 점).
- 상세: 머리(고객 · 결과 · 담당 · 카카오 방) → 문의 → 분류 교정(봇 → 상담원, 불일치면 빨강) → 처리 경과(접수·봇 판단 + audit_log 맡음/놓음/완료/다시 엶/교정/메모, 봇 완료는 done_at) → 직전 대화 → 봇 판단 → 메모 → 지난 문의. 아래 고정: 분류 교정 · 메모 · 다시 열기(admin·완료 건) / 열린 건은 「상담 큐에서 보기」.

## 통계
- 머리: 제목 · 기간 버튼(7·30·90일) · 기간 날짜 · 오른쪽 시드 스위치.
- 핵심 수치 4개는 한 테두리 안 한 줄(폰 2×2), 숫자 아래 무엇을 센 것인지 한 줄.
- 카테고리 막대(단색)·일별 면 채운 선(오늘 점 강조)은 두 칸(5:7), 폰 한 칸. 히트맵은 범례(적음→많음).

## 설정
- 왼쪽 설정 메뉴(카테고리·운영 설정·사용자, 한 줄 설명) — 767px 이하는 위쪽 탭.
- 카테고리: 「분류 시험」 한 줄 + 표(순서·이름+ID·처리 방식 알약·예상 질문 수) → 행 누르면 오른쪽 편집 패널(`?id=`, 새 카테고리는 `?id=new`). 저장 주 버튼, 삭제는 왼쪽 빨간 글자.
- 운영 설정: 자동응답 기준 · 봇 동작 · 보관과 알림 세 묶음, 행 = 이름·설명 | 단위 붙은 입력칸. 바꾼 값이 있으면 아래 저장 막대(되돌리기·저장).
- 사용자: 표 + 행 끝 메뉴(비활성화·비밀번호 초기화, 둘 다 확인 단계).
