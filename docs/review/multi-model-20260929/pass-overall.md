
## 이번 패스: 전체 평가
외부 공개·운영 투입 관점에서 이 시스템 전체를 평가한다. 보안은 별도 패스가 따로 보므로 여기서는 깊게 파지 않되, 눈에 띄면 적는다.
- 정확성: 봇 상태 머신(`src/loop.ts`·`src/handle.ts`·`src/store.ts` — 목록 감지·점유·정적 대기·경계(newCustomerMsgs)·판정 decide·전송 at-most-once·오류 카운트), 동시성·재시작·부분 실패에서 문의가 사라지거나 중복 답장되는 경로.
- 데이터 무결성: 마이그레이션·제약·트랜잭션, web API가 봇과 같은 DB를 쓰며 생기는 경합(맡기·완료·교정·설정 변경과 봇 캐시 60초).
- web 기능 정확성: /queue·/log·/stats·/settings·사용자 관리, 폴링·새로고침, 시간대(KST) 계산, 폰 폭 동작, `web/public/guide.html`(비개발자용 안내 — 설명이 실제 봇 동작과 맞는가).
- 운영 준비: 기동·재기동·로그인 풀림·백업/복구·로그·모니터링(봇 상태 배지), 배포 구성(`Dockerfile`·`web/Dockerfile`·`docker-compose.yml`), 설정 기본값.
- 테스트: 중요한 경로 중 테스트가 없는 곳, 테스트가 실제로는 아무것도 못 잡는 곳.
- 유지보수성: 과도한 복잡도·죽은 코드·문서(CLAUDE.md)와 코드의 어긋남.
